Contexte

Dans le cadre du BTS SIO, j'avais besoin d'un support pour présenter mon parcours, mes certifications, mes projets et ma veille technologique, accessible en ligne à tout moment.

Réalisation
  • Navigation par onglets : une barre en haut et une seule section affichée à la fois
  • Thème clair / sombre mémorisé dans le navigateur
  • Frise chronologique du parcours, cartes de certifications avec fenêtre de détail
  • Slider pour la veille technologique et fond animé de particules (canvas)
  • Formulaire de contact relié à Formspree
  • Mise en page adaptée aux ordinateurs et aux téléphones
Mise en ligne

Code versionné avec Git, hébergé sur GitHub et publié gratuitement avec GitHub Pages.

Compétences travaillées
  • HTML sémantique et CSS (variables, flexbox, grid, responsive)
  • JavaScript : manipulation du DOM et événements
  • Git et GitHub, publication d'un site statique

Serveur PXE iVentoy en environnement VMware ESXi (Axians)

Objectif : mettre en place un serveur de démarrage réseau (PXE) permettant de déployer des images système (Linux, Windows) sur plusieurs machines simultanément, sans support physique (USB/DVD), dans un environnement virtualisé ESXi.

Voir le détail du projet
Contexte

Projet réalisé chez Axians : déployer des postes sans clé USB ni DVD, directement depuis le réseau, depuis un serveur de démarrage PXE.

Réalisation
  • Serveur iVentoy installé sur une machine virtuelle Ubuntu Desktop dans VMware ESXi
  • Réseau virtuel isolé, dédié au déploiement
  • Démarrage des machines clientes en PXE pour installer Linux ou Windows
Compétences travaillées
  • Virtualisation avec VMware ESXi
  • Réseau : démarrage PXE et réseaux virtuels
  • Linux (Ubuntu) et déploiement de systèmes Windows
